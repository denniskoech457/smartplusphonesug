Updates in this build:
1. Once a customer selects a phone in the application, only that selected phone remains visible. A Change phone link restores the full phone list.
2. Step 4 review now shows the customer's WhatsApp number.
3. After a successful order, a 'Send application details to WhatsApp' button opens WhatsApp with the complete application details pre-filled for SmartPay support. It uses the configured support phone number.
4. Customer Dashboard now has a WhatsApp profile field that customers can update.
5. The WhatsApp number used on a new order is also saved to the customer's profile automatically.
6. Existing databases may need docs/customer-whatsapp-profile-migration.sql if the hosting DB user cannot ALTER tables automatically.
